# Marque « Step Challenge »

Le code de Step Challenge est libre ([AGPL-3.0-or-later](LICENSE)). **Le nom « Step Challenge » et son logo ne le sont pas** : la licence porte sur le code, pas sur l'identité de l'application.

Cette distinction protège les utilisateurs : quand ils installent « Step Challenge », ils doivent obtenir l'application officielle, avec ses engagements sur les données (voir les [ADR](docs/adr/)).

## Usages autorisés sans demande

- Mentionner le nom pour désigner le projet, en parler, écrire un article ou un tutoriel.
- Indiquer qu'un projet est « basé sur Step Challenge » ou « compatible avec Step Challenge ».
- Compiler et utiliser l'application ou le backend pour un usage personnel, de test ou de développement.

## Usages non autorisés

- Publier une version modifiée de l'application, sur un store ou ailleurs, sous le nom « Step Challenge » ou avec son logo.
- Utiliser un nom, un logo ou une présentation susceptibles d'être confondus avec l'application officielle.
- Laisser entendre qu'un service ou une version dérivée est approuvé par le projet sans accord écrit.

## Publier une version dérivée

C'est permis par la licence, à condition de :

1. choisir un autre nom et une autre icône ;
2. changer l'identifiant de l'application (`android.package` dans `apps/mobile/app.json`) ;
3. utiliser votre propre serveur et vos propres identifiants (OAuth, Huawei) ;
4. respecter l'AGPL : publier le code source de votre version, y compris celui du serveur si vous l'exploitez.

## Éléments concernés

- Le nom « Step Challenge ».
- Les icônes et visuels du dossier [`icons/`](icons/) et les icônes de l'application dans `apps/mobile/assets/images/`.

Pour toute question : ouvrez une issue.
